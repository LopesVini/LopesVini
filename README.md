# Vinicius Lopes

**Engenharia elétrica, software e automação. **

Gosto de sistemas que fazem alguma coisa de verdade: uma automação que elimina trabalho repetitivo, um produto que organiza uma equipe ou um circuito que se recusa a funcionar até três da manhã.

Não coleciono tecnologia. Uso o que resolve o problema.

## No que eu mexo

- energia, eletrônica, controle e automação;
- produtos web e ferramentas internas;
- inteligência artificial aplicada, sem tratar API como magia;
- bancos de dados, integrações e processos que não deveriam depender de alguém copiando e colando planilha;
- interfaces simples o bastante para ninguém precisar de treinamento.

Hoje trabalho principalmente com **TypeScript, React, Python, Supabase, PostgreSQL e APIs**. O problema vem primeiro; a stack vem depois.
