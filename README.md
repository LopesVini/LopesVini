# Vinicius Lopes

**Electrical engineering, software, and automation.**

I like systems that do something real: an automation that kills repetitive work, a product that helps a team stay organized, or a circuit that refuses to work until three in the morning.

I don't collect technologies. I use whatever solves the problem.

## What I work on

- energy, electronics, control, and automation;
- web products and internal tools;
- applied AI, without pretending an API is magic;
- databases, integrations, and processes that should not depend on someone copying and pasting a spreadsheet;
- interfaces simple enough that nobody needs training.

I mainly work with **TypeScript, React, Python, Supabase, PostgreSQL, and APIs**. The problem comes first; the stack comes second.
